## Ro-ràdh

Tha [Visual Studio Code](https://code.visualstudio.com/) na dheasaiche còd 
stòiridh a chaidh a leasachadh le Microsoft airson Windows, Linux agus macOS (a’ 
gabhail a-steach Macs M1). Tha taic ann airson dì-bhugachadh, smachd Git agus 
GitHub freumhaichte, soillseachadh co-chàradh, crìochnachadh còd tuigseach, 
snippets, agus ath-structaradh còd.

’S e prìomh fheart an deasaiche gu bheil e sùbailte agus gu bheil cruinneachadh 
mòr de leudachain aige, air an cumail suas le luchd-cleachdaidh agus le 
Microsoft fhèin.

Mar ro-ràdh coitcheann, seo taisbeanadh mun chuspair
<a href="https://www.renekreijveld.nl/slides/juglondon/vscode.pdf"
rel="nofollow noreferrer noopener">Leasachadh Joomla le Visual Studio
Code (PDF, 1Mb)</a>, le René Kreijveld, leasaiche Joomla aig Destiny B.V. Joomla User
Group London, 16mh Am Màrt 2021.

Air an duilleag seo, tha sinn a’ mìneachadh liosta de leudachain a thathar a’

## Rèiteachadh Dì-bhugadair PHP

Tha an leudachan a’ cur taic ris na rèiteachaidhean PHP as cumanta aig
<a href="https://xdebug.org/"
rel="nofollow noreferrer noopener">XDebug</a>. Bidh e ag amalachadh gu tur
na feartan VSCode uile airson sgriobtaichean PHP a dhì-bhugachadh.

Gus an leudachan a rèiteachadh, tadhail air na sgrìobhainnean oifigeil

Mar eisimpleir de rèiteachadh airson dì-bhugachadh VSCode, seo launch.json
cumanta:

    {
        // Use IntelliSense to learn about possible attributes.
        // Hover to view descriptions of existing attributes.
        // For more information, visit: https://go.microsoft.com/fwlink/?linkid=830387
        "version": "0.2.0",
        "configurations": [

            {
                "name": "Listen for XDebug",
                "type": "php",
                "request": "launch",

                // Server Remote XDebug Port - 9000 is the default XDebug port
                "port": 9000,

                // Server Remote Path -> Local Project Path
                "pathMappings": {
                    "/app/www": "${workspaceRoot}/www"
                }
            },
            {
                "name": "Launch currently open script",
                "type": "php",
                "request": "launch",
                "program": "${file}",
                "cwd": "${fileDirname}",

                // Local XDebug Port - 9000 is the default XDebug port
                "port": 9000
            }
        ]
    }

A thaobh an rèiteachaidh launch.json a tha
felixfbecker/vscode-php-debug ag iarraidh, ’s e seo rèiteachadh PHP
XDebug fhèin.

Aig an àm seo, dh’fhaodadh xdebug-2 no xdebug-3 a bhith san
àrainneachd leasachaidh agad. Tha iad eadar-dhealaichte a thaobh nam
paramadairean a tha riatanach. Gus PHP XDebug a rèiteachadh, seo na
roghainnean as cumanta airson php.ini.

### Rèiteachadh XDebug 2

[XDebug]
    ;;;;;;;;;;;;;;;;;;;
    ; xdebug-2.9.8
    ;;;;;;;;;;;;;;;;;;;
    xdebug.remote_enable = 1
    xdebug.remote_autostart = 1
    ; xdebug.remote_port = 9000

### Rèiteachadh XDebug 3

[XDebug]
    ;;;;;;;;;;;;;;;;;;;
    ; xdebug-3.0.0
    ; https://xdebug.org/docs/upgrade_guide
    ;;;;;;;;;;;;;;;;;;;
    xdebug.mode = debug
    xdebug.start_with_request = yes
    xdebug.discover_client_host = true
    ; xdebug.client_port = 9000

Gus barrachd fhaighinn a-mach mu mar a tha XDebug ag obair air an taobh a-staigh
gus ceangal ris an Deasaiche, thoir sùil air na
[sgrìobhainnean](Xdebug 3 — Documentation).

## Rèiteachadh phpcs

Gus an leudachan a rèiteachadh, tadhail air na
sgrìobhainnean oifigeil.
Tha an leudachan a’ toirt taic do na rèiteachaidhean as cumanta de
<a href="https://pear.php.net/package/PHP_CodeSniffer/"
rel="nofollow noreferrer noopener">PHP_CodeSniffer</a>.

Gu bunaiteach, thig PHP_CodeSniffer le grunn inbhean còdaidh. Aon uair
‘s a bhios an leudachan air a stàladh, obraichidh e le **PSR2**.

        "phpcs.standard": "PSR2",

Gus an leudachan a rèiteachadh gus na **Inbhean Còdaidh Joomla!** a
chur an sàs,
stàlaich na riaghailtean a’ leantainn an
iùil oifigeil
Aon uair ‘s a bhios na **Inbhean Còdaidh Joomla!** air an stàladh, rèitich na
Roghainnean Cleachdaiche a’ leantainn na rèiteachaidhe eisimpleireach seo:

        "phpcs.standard": "/home/YOUR-USER/.../Joomla",

## Rèiteachadh PHP Intelephense

Gus an leudachan a rèiteachadh, tadhail air na
sgrìobhainnean intelephense.
Chan eil feum aig an leudachan air rèiteachadh a bharrachd.

Tha VSCode a’ tighinn le taic bhunasach don chànan PHP. Mar sin, ’s dòcha
gur e deagh bheachd a th’ ann an taic bhunaiteach a chur à comas gus còmhstri a sheachnadh:

        // Disable basic suggestions
        "php.suggest.basic": false,

        // To activate code suggestions in comments
        "editor.quickSuggestions": { "comments": true },

Mar roghainn eile, tha leudachan mòr-chòrdte eile ann cuideachd: **PHP
IntelliSense** <a
href="https://marketplace.visualstudio.com/items?itemName=felixfbecker.php-intellisense"
rel="nofollow noreferrer noopener">felixfbecker.php-intellisense</a>
Taic adhartach airson fèin-chrìochnachadh agus ath-structaradh ann am PHP.

## Rèiteachadh PHPUnit

Gus an leudachan a rèiteachadh, tadhail air sgrìobhainnean vscode phpunit

Tha an leudachan a’ fighe a-steach
<a href="https://phpunit.de/"
rel="nofollow noreferrer noopener">PHP Unit</a> le VSCode, agus mar sin tha na
feartan uile aig PHP Unit air am fighe a-steach le VSCode agus faodar an
rèiteachadh cuideachd airson barrachd amalachaidh leis an eadar-aghaidh chleachdaiche.

Seo rèiteachadh eisimpleireach den leudachan:

        "phpunit.preferRunClassTestOverQuickPickWindow": true,
        "phpunit.driverPriority": [
            "Path",
            "Command",
            "Composer",
            "Phar",
            "Ssh",
            "GlobalPhpUnit"
        ],

Gus an leudachan a rèiteachadh, tadhail air sgrìobhainnean vscode php cs fixer.
Tha an leudachan a’ fighe a-steach
<a href="https://github.com/FriendsOfPHP/PHP-CS-Fixer"
rel="nofollow noreferrer noopener">PHP-CS-Fixer</a> le VSCode, agus mar sin tha na
feartan uile aig PHP-CS-Fixer air am fighe a-steach le VSCode agus faodar an
rèiteachadh cuideachd airson barrachd amalachaidh leis an eadar-aghaidh chleachdaiche.

Gus PHP-CS-Fixer a chur an sàs gu fèin-obrachail ann am faidhlichean PHP, rèitich na
roghainnean chleachdaiche mar seo:

        "[php]": {
            "editor.defaultFormatter": "junstyle.php-cs-fixer",
        },
        "php-cs-fixer.onsave": true,

## Rèitich EditorConfig airson VS Code

’S e fòrmat faidhle agus cruinneachadh de phluganan deasaiche teacsa a th’ ann an
EditorConfig airson stoidhlichean còdaidh cunbhalach a chumail eadar diofar luchd-deasachaidh agus IDEan.

Gus an deasaiche a rèiteachadh a rèir do roghainnean, cruthaich faidhle
.editorconfig:

    ; EditorConfig helps developers define and maintain consistent
    ; coding styles between different editors and IDEs.

    ; For more visit http://editorconfig.org.
    root = true

    ; Choose between lf or rf on "end_of_line" property
    [*]
    charset = utf-8
    end_of_line = lf
    indent_size = 2
    indent_style = space
    insert_final_newline = true
    trim_trailing_whitespace = true

    # editorconfig-tools is unable to ignore longs strings or urls
    max_line_length = null

    [*.html]
    indent_style = tab

    # PSR-2
    # [*.php]
    # indent_size = 4
    # indent_style = space

    # Joomla! Coding Standards
    [*.php]
    indent_size = 4
    indent_style = tab

    [*.md]
    trim_trailing_whitespace = false

    [*.yml]
    indent_style = space
    indent_size = 2
